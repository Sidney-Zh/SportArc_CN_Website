先按要求固定手机，保持同一个角度

比赛复盘需要固定角度拍摄的乒乓球录像。参照示例，拍清球台、球和两侧球员，录像过程中保持手机位置不变。切换机位或拼接不同角度的素材，不符合这项分析的拍摄要求。

常见问题

使用前，先确认这些问题。

和手动记录比分有什么区别？

比赛复盘从你导入的乒乓球视频进行分析，提供落点、击球数据和报告。它的输入与用途不同于只填写比分和胜负的记分工具。

和自动剪辑怎么选？

想把录像里的回合存成视频，选自动剪辑；想结合落点和击球数据回看乒乓球比赛，选比赛复盘。两者的拍摄要求也需要分别确认。

可以用它看单个挥拍动作吗？

查看支持技术的 3D 动作、动作指标和反馈，可以使用 AI 教练。比赛复盘侧重比赛与击球数据。

支持网球和羽毛球比赛数据吗？

比赛复盘目前提供给乒乓球。网球和羽毛球可以通过自动剪辑检查回合并导出视频。

支持哪些设备？

迹时运动 支持 iPhone 和 iPad，可免费下载，提供 App 内购买。功能使用条件和 Plus 权益请以 App 内说明为准。
