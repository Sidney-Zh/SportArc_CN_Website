一、我们如何收集和使用您的信息

1. 注册、登录我们的账号

当您注册、登录我们的产品及相关服务时，您可以通过手机号创建账号，我们将通过发送短信验证码来验证您的身份是否有效，并且您可以完善相关的网络身份识别信息（昵称、密码、手机号），收集这些信息是为了帮助您完成注册。您还可以根据自身需求选择填写性别、生日、地区及介绍信息完善您的个人信息。

2. 产品的正常运行

当您使用我们的相关服务时，为了保障软件与服务的正常运行，以及第三方支付分享功能的正常使用，我们会收集以下数据：

2.1 硬件型号、操作系统版本号、软件版本号、网络接入方式及类型、操作日志信息（错误信息）。收集这些信息，有助于我们了解您使用过程中遇到的问题，优化我们的产品。

2.2 使用情况信息的收集与分析。为保障产品功能的正常运行、提升性能、定位并解决您在使用过程中可能遇到的问题，我们可能在您使用应用及相关服务时记录与运行状态有关的必要信息，包括网络请求日志、崩溃日志、功能使用频率、性能数据及整体使用情况等。该类信息不涉及可用于直接识别您个人身份的内容，仅用于产品运维、安全保障及服务优化。

3. 商品/服务信息展示

若您成为我们的注册用户，我们可能通过应用内通知、电子邮件或其他方式向您发送与服务更新、功能优化或活动信息相关的商业性通知。您有权随时选择退订或关闭相关通知；若您不同意接收，该行为不会影响您正常使用核心功能。

4. 设备权限调用

在提供特定功能时，我们可能需要您授权应用访问某些系统权限。我们仅会在实现相应功能所必须的范围内申请权限，且不会在未授权情况下擅自访问您的设备信息。您有权拒绝授权，拒绝后不影响基本功能的使用，但部分依赖该权限的功能可能无法正常提供。

4.1 相册访问权限：当您需要上传本地图片或视频等内容时，我们将请求相册访问权限。未授权该权限不会影响应用其他功能的正常使用，但相关上传功能将无法实现。

5. 第三方 SDK 使用说明

为实现文件上传、下载、性能优化等必要功能，我们的应用中可能集成第三方技术服务提供方提供的软件开发工具包（SDK）。第三方 SDK 将严格遵守最小必要原则，执行与功能实现相关的技术处理活动，并按照法律法规及双方协议要求采取相应的安全保护措施。我们会对接入的第三方 SDK 进行严格安全评估，并要求其遵守不低于本隐私政策的数据保护标准，仅在实现功能所必需的范围内收集和使用个人信息。在您使用第三方服务前，我们建议您查阅其相关隐私政策，详情请阅读下列《乒派第三方信息共享清单》

二、身份识别与会话机制

为了在您使用本服务期间识别您的身份并维持登录状态，我们会在您登录或完成身份验证后在客户端存储会话标识（如会话令牌）。该类标识仅在一定期限内有效，到期后将失效或被更新，以保障您的账号与服务安全。

我们可能出于以下目的使用上述会话标识：

  1. 身份验证与会话维持：用于确认您的当前登录状态，使您在使用服务过程中无需反复输入账号及密码；
  2. 提升服务体验：用于支持页面跳转及功能切换，保障您获得连贯、流畅的使用体验；
  3. 安全保障：用于识别异常行为、验证请求合法性、预防欺诈及防止违反用户协议的行为；
  4. 系统运行与质量优化：用于协助我们提升服务的稳定性、性能及整体质量。

除为实现上述目的外，我们不会将该类会话标识用于本政策未载明的其他用途。

三、我们如何共享、公开披露您的个人信息

1. 共享

我们不会与任何公司、组织或个人共享您的个人信息，但以下情形除外：

1.1 经您单独授权或同意的共享

在获得您的明确授权或同意后，我们会根据授权范围向指定的第三方共享您的个人信息。该等共享仅在必要范围内进行，并受本政策及您同意内容的约束。

1.2 法定情形下的共享

在法律法规规定的范围内，或依据行政机关、司法机关依法作出的要求，我们可能在履行相应法定义务的前提下共享您的个人信息。在共享前，我们将依法审核相关要求的合法性和必要性。

1.3 经营变更情形下的共享

若发生合并、分立、重组、收购、资产转移或破产清算等经营变更情形导致您的个人信息可能被转移，我们将要求个人信息接收方继续受本隐私政策的约束。如接收方需要变更个人信息处理目的或方式，我们将要求其另行征得您的授权或同意。

1.4 与授权合作伙伴共享

1.4.1 第三方 SDK 使用的权限及功能说明

为实现文件上传、下载、网络传输管理等必要产品功能，我们的应用集成了由第三方技术服务提供方提供的软件开发工具包（SDK）。该 SDK 可能需要在您的授权下使用与网络访问、文件读取或写入相关的系统能力，以保证相关功能的正常运行。我们将严格按照最小必要原则，对第三方 SDK 使用的系统能力进行审慎评估，并要求第三方技术服务提供方遵守法律法规、履行个人信息保护义务，并采取相应的安全保护措施，确保您的个人信息不被用于未经授权的目的。

1.4.2 第三方 SDK 收集的个人信息类型及使用目的

为保障上传、下载、网络链路调度、性能监测等功能的正常实现，第三方 SDK 可能会根据您在使用相关功能时的实际操作和授权情况，收集与网络状态、系统运行环境、文件读写操作等相关的必要信息。上述信息仅用于实现功能所需、提升服务稳定性、排查异常情况及保障数据传输安全。第三方 SDK 收集的个人信息将遵循数据最小化原则，并采取加密传输、访问控制等安全措施进行处理。我们仅会允许第三方 SDK 在本政策所述目的范围内处理相关信息，不会将其用于未经授权的用途，也不会主动向第三方提供可识别您身份的个人敏感信息。

2. 委托处理

2.1 委托处理的情形

为向您提供相关产品或服务、保障服务质量与稳定性，我们可能委托经审慎评估的合作伙伴代为处理与服务功能实现相关的个人信息。我们仅会基于合法、正当、必要、特定、明确的目的开展委托处理活动，并仅向受托方提供为实现委托目的所必需的个人信息。在委托合作伙伴处理个人信息前，我们将与其签署严格的数据处理协议，要求其按照本隐私政策、双方约定及适用法律法规处理个人信息，不得将受托处理的个人信息用于任何未经授权的目的。如受托方需变更处理目的或方式，将由其再次征得您的同意。

2.2 委托处理的合作伙伴类型

我们可能委托的合作伙伴类型包括但不限于：

2.2.1 技术服务类合作伙伴：为实现文件存储、数据传输、网络优化、基础设施支持等功能，我们可能委托提供云计算、存储服务、网络请求处理等技术能力的合作伙伴代为处理相关信息，以保障服务稳定运行。

2.2.2 数据处理与运营支持类合作伙伴：为提升服务性能、定位技术问题，或实现必要的统计分析，我们可能委托具备合规能力的合作伙伴处理与系统运行状态、网络表现或功能使用情况相关的必要信息。该等合作伙伴不会处理与您个人身份直接关联的敏感信息。

2.3 受托方的管理与监督

对于受托处理个人信息的合作伙伴，我们将持续监督其履行个人信息保护义务，包括但不限于安全管理措施、访问控制、数据保存与删除要求等。如合作伙伴存在违反协议或法律法规的行为，我们将及时采取暂停服务、终止合作等措施，并依法要求其承担相应责任。

3. 公开披露

我们不会主动公开披露您的个人信息。仅在符合法律法规或取得您单独同意的情况下，方可能公开披露您的个人信息。公开披露将以符合业界标准的安全保护措施为前提。

3.1 经您单独同意的披露

在您明确授权的范围内，并按照您指定的信息类型、披露方式及披露对象，我们可能公开披露您授权的信息。

3.2 法定披露

在法律法规、司法程序、行政执法或政府主管部门强制要求的情况下，我们可能按照要求披露您的个人信息。在披露前，我们将依法审核相关要求，并在符合法律法规的前提下，要求提出请求的机构提供相应的法律文书（如传票、调查函等），同时仅披露必要范围的信息。

四、个人信息安全保护

  1. 为提高您使用我们提供的服务的安全性，我们通过不断提升的技术手段加强安装在您设备端的软件的安全能力，以防止您的个人信息泄露。我们建立专门的管理制度、流程和组织以保障信息的安全。我们会尽全力保护您的个人信息，我们也请您理解，任何安全措施都无法做到无懈可击。
  2. 我们努力为用户的信息安全提供保障，以防止信息的泄露、丢失、不当使用、未经授权访问和披露等。我们使用多方位的安全保护措施，以确保用户的个人信息保护处于合理的安全水平，包括技术保护手段。管理制度控制、安全体系保障等诸多方面。同时，我们采用业界领先的技术保护措施。我们使用的技术手段包括但不限于防火墙、加密（例如SSL）、去标识化或匿名处理、访问控制措施等。此外，我们还会不断加强安装在您设备端的软件的安全能力。例如，我们会在您的设备本地完成部分信息加密工作，以巩固安全传输；我们会了解您设备安装的应用信息和运行中的进程信息，以预防病毒、木马等恶意程序。
  3. 在不幸发生个人信息安全事件后，我们会立即成立专项应急小组，启动应急预案，防止安全事件扩大，并按照法律法规的要求及时向您告知：安全事件的基本情况和可能的影响、我们已采取或将要采取的处置措施、您可自主防范和降低风险的建议、对您的补救措施等。我们将及时将事件相关情况以邮件。信函、电话、推送通知等方式告知您，难以逐一告知个人信息主体时，我们会采取合理、有效的方式发布公告。同时，我们还将按照监管部门要求，主动上报个人信息安全事件的处置情况。

五、信息保存期限

  1. 我们仅在实现本政策所述目的所必需的最短时间内保存您的个人信息，且会在符合法律法规要求的前提下，尽量缩短保存期限。
  2. 一般情况下：
    1. 账号信息：在您使用本应用期间持续保存；当您注销账号时，我们将删除或对其进行匿名化处理，但法律法规另有规定的除外。
    2. 日志与诊断信息：为保障服务安全及排查问题，我们通常自收集之日起保存不超过6个月，期限届满后将删除或匿名化处理。
    3. 与交易相关的信息：为履行税务、财务或监管义务，我们会自交易完成之日起保存不少于3年，期满后将删除或匿名化处理，或按照法律法规要求的更长期限予以保存。
  3. 当我们终止部分或全部服务时，我们将及时停止相关个人信息的收集活动，并在合理期限内对所持有的个人信息进行删除或匿名化处理，但法律法规另有规定或监管机构另有要求的除外。

六、您如何管理个人信息

您可以通过以下方式查阅和管理您的信息，我们会在符合法律法规要求的情形下响应您的请求：

1. 访问您的个人信息

您有权访问您的个人信息，法律法规规定的例外情况除外。您可以通过以下方式自行访问您的个人信息：

个人资料——如果您希望访问或编辑您个人资料中的出生年月日、用户名以及手机号码其他资料等，您可以通过登录账户通过"我的"-"个人设置"中执行此类操作。

授权使用——您可以登录账号通过点击右上角"设置"图标，点击"头像"-"设置"，在授权选项中关闭或启用授权。

2. 更正或补充您的个人信息

当您发现我们处理的关于您的个人信息有错误时，您有权要求我们做出更正或补充。您可以通过本条"（一）访问您的个人信息"中列明的方式提出更正或补充申请。

3. 删除您的个人信息

您可以通过本条"（一）访问您的个人信息"中列明的方式删除您的部分个人信息。

在以下情形中，您可以通过客服向我们提出删除个人信息的请求：

3.1 如果我们处理个人信息的行为违反法律法规；

3.2 如果我们收集、使用您的个人信息，却未征得您的明确同意；

3.3 如果我们处理个人信息的行为严重违反了与您的约定；

3.4 如果您不再使用我们的产品或服务，或您注销了账号；

3.5 如果我们不再为您提供产品或服务。

若我们决定响应您的删除请求，我们还将同时尽可能通知从我们处获得您的个人信息的主体，并要求其及时删除（除法律法规另有规定，或这些主体已独立获得您的授权）。

4. 改变您授权同意的范围

每个业务能需要一些基本的个人信息才能得以完成（见本隐私权政策"第一条"）。除此之外，对于额外个人信息的收集和使用，对于基于系统权限获取的信息（如相册访问权限等），您可以在设备的"设置"-"隐私设置"中随时关闭相应权限；关闭后，我们将不再通过该权限收集相关信息。

5. 约束信息系统自动决策

在某些业务功能中，我们可能仅依据信息系统、算法等在内的非人工自动决策机制做出决定。如果这些决定显著影响您的合法权益，您可以通过客服联系我们。

6. 响应您的上述请求

为保障安全，您可能需要提供书面请求，或以其他方式证明您的身份。我们可能会先要求您验证自己的身份，然后再处理您的请求。

我们将在15个工作日内做出答复。如您不满意，还可以通过本应用客服发起投诉。

对于您合理的请求，我们原则上不收取费用，但对多次重复、超出合理限度的请求，我们将视情收取一定成本费用。对于那些无端重复、需要过多技术手段（例如，需要开发新系统或从根本上改变现行惯例）、给他人合法权益带来风险或者非常不切实际的请求，我们可能会予以拒绝。

在以下情形中，按照法律法规要求，我们将无法响应您的请求：

6.1 与国家安全、国防安全直接相关的；

6.2 与公共安全、公共卫生、重大公共利益直接相关的；

6.3 与犯罪侦查、起诉、审判和执行判决等直接相关的；

6.4 有充分证据表明您存在主观恶意或滥用权利的；

6.5 响应您的请求将导致您或其他个人、组织的合法权益受到严重损害的；

6.6 涉及商业秘密的。

7. 账号注销

您可以在【我的-设置-账号注销】中申请注销您的账号。账号注销成功后，我们将立即停止为您提供产品或服务，并对与该账号相关的个人信息进行删除或匿名化处理，不再继续保留您的账号数据；但法律法规另有规定或为履行监管义务、解决争议纠纷确需在一定期限内保存的除外，在此情况下我们仅在必要范围和期限内保存，并在期限届满后删除或匿名化处理。我们不会以不合理条件对您的注销申请设置障碍，例如强制您同意额外收集个人信息或长期保留与注销无关的数据。

如果您无法通过上述路径访问该等个人信息，您可以随时通过本应用客服与我们取得联系。我们将在15个工作日内回复您的访问请求。

  3. 如果我们发现自己在未事先获得可证实的父母或法定监护人同意的情况下收集了未成年人的个人信息，我们会设法尽快删除相关数据。

十、名词解释

个人信息：个人信息是指以电子或者其他方式记录的能够单独或者与其他信息结合识别自然人个人身份的各种信息，包括但不限于自然的姓名、出生日期、身份证件号码、个人生物识别信息、住址、电话号码等。

个人敏感信息：个人敏感信息是指一旦泄露、非法提供或滥用可能危害人身和财产安全，极易导致个人名誉、身心健康受到损害或歧视性待遇等的个人信息。例如，个人敏感信息包括身份证件号码、个人生物识别信息、银行账号、通信内容、健康生理信息等。

去标识化：指通过对个人信息的技术处理，使其在不借助额外信息的情况下，无法识别个人信息主体的过程。

匿名化：指通过对个人信息的技术处理，使得个人信息主体无法被识别，且处理后的信息不能被复原的过程。

儿童：指不满十四周岁的未成年人。
